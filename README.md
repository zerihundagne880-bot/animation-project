# ✨ CSS Magic Shapes - Animation Project

ይህ ፕሮጀክት በ CSS3 ብቻ የተሰሩ ዘመናዊ እና ተንቀሳቃሽ ቅርጾችን (Animated Shapes) ያሳያል። እያንዳንዱ ቅርጽ የራሱ የሆነ የባህርይ እንቅስቃሴና ውበት አለው።

[![Visit Demo](https://img.shields.com/badge/View%20Animation-🚀-ff69b4?style=for-the-badge)](https://zerihundagne880-bot.github.io/mylistingapp/Animation.html)

## 🚀 ዋና ዋና አኒሜሽኖች

* **The Pulser:** ከለሩን እየቀያየረ የሚተነፍስ (Scale) ቀይ ሳጥን።
* **The Floater:** ወደ ላይና ወደ ታች እየተንሳፈፈ የሚወዛወዝ ብርቱካናማ ሳጥን።
* **The Spinner:** ሳይቆም በለሰለሰ ሁኔታ የሚዞር ወይን ጠጅ ሳጥን።
* **Interactive Hover:** ሳጥኖቹን በምትነካበት ጊዜ ይበልጥ ያበራሉ!

## 🛠 ቴክኒካዊ ዝርዝር

ይህ ፕሮጀክት የሚከተሉትን የ CSS ቴክኒኮች ይጠቀማል፦
- **Keyframes:** ለእንቅስቃሴ ቁጥጥር።
- **Transitions:** ለለሰለሰ ምላሽ።
- **Linear Gradients:** ለገጹ ውብ ዳራ (Background)።
